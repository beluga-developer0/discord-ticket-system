 # 📩 Beluga Support System — Ticket Center v1.0.0

![Python](https://shields.io)
![Discord.py](https://shields.io)
![Status](https://shields.io)

**Beluga Support System** — это продвинутая автономная тикет-система для Discord-серверов, построенная на базе современных интерактивных кнопок (`discord.ui.View`) и всплывающих модальных окон (`discord.ui.Modal`). Бот работает на 100% локально и полностью защищен от перезапусков.

---

## 🛠️ Возможности системы

*   **📩 Кастомный интерфейс каналов**: Автоматическая генерация приватных чатов с красивой разметкой, эмодзи и порядковым номером (`📩︱тикет-0001`).
*   **🎛️ Интерактивный пульт (4-в-1)**: Внутри каждого обращения доступна панель управления для закрытия тикета, пинга старшей администрации, вызова модального окна добавления участников и скачивания логов на лету.
*   **🔒 Постоянные кнопки (Persistent Views)**: Специальный алгоритм сканирует открытые сессии при старте скрипта и полностью восстанавливает работоспособность всех кнопок на сервере, даже если бот перезапускался.
*   **📜 Авто-транскрипты**: Логирование переписки в файлы `.txt` с отправкой подробного Embed-отчета в архивный канал аудита администрации.

---

## ⚙️ Установка и запуск

### 1. Установка библиотек
Перед первым запуском установите актуальную версию библиотеки `discord.py`:
```bash
pip install discord.py
```

### 2. Запуск скрипта
Запустите файл бота через консоль Windows:
```bash
python "discord-ticket-system.py"
```
При первом старте бот интерактивно попросит ввести токен вашего Discord-приложения в консоль и сгенерирует файлы конфигурации `ticket_config.json` и `ticket_creators.json`.

## 📋 Список гибридных команд (! и /)

Все команды управления полностью раздвоены и поддерживают одновременный вызов через текстовые сообщения и слэш-меню:


| Команда | Описание | Доступ |
| :--- | :--- | :--- |
| `!тикет-панель` / `/тикет-панель` | Отправить Embed-панель с кнопкой открытия обращений в текущий канал | Только Владелец |
| `!тикет-саппорт` / `/тикет-саппорт` | `[добавить/удалить]` Привязать роль модераторов, которые будут видеть новые тикеты | Только Владелец |
| `!тикет-админ` / `/тикет-админ` | `[добавить/удалить]` Привязать роль старшей администрации для экстренного вызова | Только Владелец |
| `!тикет-логи` / `/тикет-логи` | Установить текстовый канал для отправки `.txt` транскриптов закрытых обращений | Только Владелец |
